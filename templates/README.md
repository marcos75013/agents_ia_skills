# Modèles

- [`new-project/PROJECT_BRIEF.md`](new-project/PROJECT_BRIEF.md) : cadrer un nouveau projet avant les choix structurants.
- [`existing-project/AUDIT_BRIEF.md`](existing-project/AUDIT_BRIEF.md) : observer un projet existant avant toute migration.
- [`project-instructions/AGENTS.template.md`](project-instructions/AGENTS.template.md) : point de départ concis pour les instructions propres à un dépôt.

Copier le modèle utile dans le projet cible, le compléter puis supprimer les rubriques sans objet. Un modèle n'est pas une règle universelle.
