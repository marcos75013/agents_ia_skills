# Workflows GitHub

Ce dossier documentera et préparera les workflows réutilisables. Un workflow réellement activé dans ce dépôt ou un projet cible doit être placé sous `.github/workflows/`.

## Garde-fous futurs

- permissions minimales et versions d'actions figées ;
- lint, tests et analyse de sécurité avant intégration ;
- environnements protégés et approbation pour la production ;
- secrets fournis par GitHub, jamais écrits dans les fichiers ou logs ;
- aucune voie de déploiement contournant les contrôles obligatoires ;
- estimation des minutes, stockage et quotas pour limiter les coûts.

Aucun pipeline de production n'est créé pendant cette mission.
