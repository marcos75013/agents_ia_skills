# Angular / TypeScript audit profile

Read only when Angular is detected.

- Establish Angular, TypeScript, Node and package-manager versions from manifests, lockfiles and configuration; distinguish constraints from observed runtime versions.
- Map applications/libraries, standalone versus NgModule organization, routes, rendering mode, state, services, HTTP boundaries and generated clients.
- Inspect strictness, lint/test/build targets, environment configuration, bundle budgets and dependency duplication.
- Review semantic HTML, keyboard/focus behavior, dynamic announcements, contrast evidence and motion preferences on critical journeys.
- Examine lazy loading, change detection/signals appropriate to the detected version, asset optimization, transfer size and server/client rendering costs. Do not recommend APIs unsupported by the project version.
