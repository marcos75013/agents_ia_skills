# Java / Spring Boot audit profile

Read only when Spring Boot is detected.

- Establish Java, Spring Boot, Maven/Gradle and database versions from build and wrapper files; distinguish configured targets from installed runtimes.
- Map controllers/adapters, application services/use cases, domain logic, persistence, transactions, messaging, scheduled work and external clients.
- Review validation and error contracts, constructor injection, transaction boundaries, schema migration ownership and observability.
- Inspect Spring Security defaults, authorization tests, CORS/CSRF choices, actuator exposure, secret configuration and dependency management.
- Assess unit, slice, integration, container and contract tests according to risk; never start services, containers or migrations without authorization.
- Check JVM/container limits, connection pools, query behavior, cold starts and deployment scaling before estimating cost or performance.
